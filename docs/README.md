## Artefacts / Templates

`assets/templates/` contains the canonical reusable artefacts.

Principle:

> **Use the smallest set of artefacts that answers the discovery objective.**

Templates preserve:

- evidence;
- stable IDs;
- validation status;
- confidence;
- contradictions;
- `UNKNOWN`;
- Golden Thread links.

## Methodological Precedence

If a practitioner chapter, template, prompt or AI instruction conflicts with `docs/methodology/`, the canonical methodology wins.

When the canonical methodology changes, derived content should be reviewed for alignment.
