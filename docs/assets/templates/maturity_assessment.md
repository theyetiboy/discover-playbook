# Cross-Dimension Observations

Identify interactions between dimensions.

Examples:

- Defined process but weak information ownership
- Strong technology but weak adoption
- Good reporting capability but limited value measurement
- Strong specialist knowledge concentrated in a small number of people

## Guidance

- Do not infer low maturity merely because evidence was not supplied.
- Mark evidence gaps explicitly.
- A maturity assessment should help target improvement, not create a vanity score.
- Different dimensions are expected to mature at different rates.
