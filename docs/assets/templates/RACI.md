# RACI Matrix

> A RACI Matrix defines the roles and responsibilities associated with business capabilities, processes, activities and decisions. It provides clarity over ownership, accountability and collaboration, helping to reduce ambiguity and improve governance.

The purpose of this RACI Matrix is to:

- Clarify ownership
- Reduce ambiguity
- Improve governance
- Support decision making
- Identify gaps in accountability
- Improve cross-functional collaboration

---

# RACI Definitions

| Role | Description |
|------|-------------|
| **R** | **Responsible** – Performs the work required to complete the activity. |
| **A** | **Accountable** – Ultimately answerable for the outcome and decision. There should normally be one accountable owner. |
| **C** | **Consulted** – Provides expertise or input before decisions are made. |
| **I** | **Informed** – Kept informed of progress or outcomes but is not directly involved in the work. |

# Good Practice

When creating a RACI Matrix:

- Ensure each activity has only **one Accountable (A)** owner.
- Avoid assigning everyone as Responsible.
- Keep Consulted (C) roles focused on subject matter expertise.
- Use Informed (I) only where updates are genuinely required.
- Review the matrix with stakeholders to confirm ownership and accountability.
