## Important Design Decisions

1. `docs/methodology/` is authoritative.
2. DISCOVER is iterative, not waterfall.
3. Workshops select only the POPIT-V lenses required.
4. Decisions drive information/data requirements.
5. Evidence is distinguished from stakeholder statement and assumption.
6. `UNKNOWN` is acceptable and preferable to invented certainty.
7. Stable IDs provide traceability where useful.
8. Broken Threads are surfaced.
9. Data-product hypotheses may emerge during discovery but are not prematurely committed.
10. AI is a candidate capability, not a default solution.
11. Roadmapping is outcome-led and distinct from sprint/release planning.
12. Value is explicit throughout the methodology.

## Recovery / Reconstruction Note

This candidate has been assembled from the substantive working DISCOVER material that remained available, then reconstructed and enriched where earlier source copies were incomplete.

The supporting technique, POPIT-V, appendix and template material has been brought to a consistent practitioner-reference standard rather than being represented by abbreviated summaries.

Current external references were refreshed against recognised professional bodies and official standards sources during the August 2026 consolidation.

## Baseline Procedure

Before declaring this version final:

1. review the repository structure;
2. sample the enriched chapters for tone/depth;
3. test the NotebookLM workflow using the Finance simulation;
4. identify contradictory instructions or weak prompts;
5. run a final content/link audit;
6. tag the accepted commit as the first stable baseline.

Package-level validation and manifests are generated outside the public repository.
